BACKGROUND & CONTEXT

Introduction: What is Cyber Threat Intelligence?

💡 The Role of CTI in Modern Defense
Cyber Threat Intelligence (CTI) is structured, actionable knowledge about active threat actors, malware campaigns, and Indicators of Compromise (IOCs) that allows organizations to anticipate and block cyber attacks before damage occurs.
Unstructured Data Deluge
  • Threat reports, vendor blogs, and PDFs are published daily in free-form text.
  • Perimeter security tools (firewalls, SIEM) cannot ingest unstructured English text.
The Analyst Bottleneck
  • Security analysts manually copy and paste IPs, hashes, and CVEs for 3–5 hours per report.
  • Slow manual triage creates high adversary dwell time (16 days undetected).
Our Solution
  • NLP & Regex automatically extract IOCs and map MITRE techniques in sub-seconds.
  • Builds a queryable Knowledge Graph and generates instant defensive playbooks.

PROBLEM DEFINITION

Problem Statement: Challenges in Modern SOCs

1. Unstructured Data Overload
Over 85% of actionable threat intelligence is published in unstructured text format (blogs, CISA bulletins, PDF advisories). Security devices cannot parse free-form text.
2. Manual Analyst Burnout
SOC analysts spend hundreds of hours per week manually extracting IOCs. High fatigue leads to typos, missed indicators, and delayed incident containment.
3. Inconsistent ATT&CK Mapping
Classifying attacker techniques into the MITRE ATT&CK framework requires deep domain expertise. Different analysts map the same attack behavior inconsistently.
4. Disconnected, Siloed Intelligence
A standalone malicious IP provides zero context. Analysts need to know: Which APT group controls it? What malware communicates with it? Relational graphs are absent.

Aim & Key Research Objectives

To engineer an automated, end-to-end Cyber Threat Intelligence pipeline using NLP and LLMs to ingest unstructured security text, extract threat entities, standardize behaviors against MITRE ATT&CK, construct a Knowledge Graph, and generate instant defensive playbooks.

04. Knowledge Graph

STAGE 1 DEEP-DIVE

Stage 1: Dual-Layer Named Entity Recognition

Layer A: Deterministic Regex IOC Engine
  • IPv4 & IPv6 Addresses: Octet validation extracts active C2 and listener nodes.
  • Domains & Defanged URLs: Automatically cleans silentc2[.]net formats.
  • Cryptographic Hashes: 32-hex MD5, 40-hex SHA-1, and 64-hex SHA-256 signatures.
  • Vulnerabilities (CVE): Case-insensitive regex matching CVE-YYYY-NNNNN.
  • Registry Keys: Captures HKCU / HKLM Run persistence keys.
  • Scheduled Tasks: Captures stealth task names (e.g. WindowsUpdateTask).
Layer B: spaCy NLP Linguistic Engine
  • spaCy en_core_web_sm: Extracts ORG, PERSON, and PRODUCT entity labels.
  • Threat Actor Classification: Heuristic filters match APT, BEAR, SPIDER, PANDA, and FIN groups.
  • Malware Family Detection: Identifies backdoors, ransomware, and custom trojans.
  • Normalization & Deduplication: Cleans noise and case-folds duplicate entities.
  • Sub-Millisecond Speed: Precompiled regex patterns execute in sub-milliseconds.

STAGE 2 DEEP-DIVE

Stage 2: MITRE ATT&CK Classification Engine

Standardizing Adversary Tactics
  • 100+ Enterprise Techniques: Pre-mapped across all 14 MITRE tactics.
  • Semantic Keyword Matching: Translates human phrases (e.g. "spear-phishing attachment" to T1566, "DNS tunneling" to T1071).
  • Kill-Chain Tactic Resolution: Automatically resolves each technique to its parent phase (TA0001 Initial Access through TA0040 Impact).
  • Automated Posture Audit: Allows SOC teams to see which attack phases are actively targeted.

STAGE 3 & 4 DEEP-DIVE

Stage 3 & 4: Knowledge Graph & Threat Scoring

NetworkX Directed Knowledge Graph
  • Relational Triples: Connects entities into Subject-Predicate-Object triples with confidence weights.
  • Example: (APT29) ──[uses]──▶ (SilentHorn) ──[c2]──▶ (185.132.189.10).
  • Multi-Hop Traversal: Uncovers shared C2 servers used across separate attacks.
  • Degree Centrality: Highlights high-risk core infrastructure.
  • D3.js Visualization: Built-in export_d3() JSON for web rendering.
Objective Threat Severity Scoring (0–10)
  • Entity Weights: Threat Actor (+15), Zero-Day CVE (+10), Malware (+10), C2 IP (+5).
  • Tactic Weights: Exfiltration (+20), Impact (+20), C2 (+15), Persistence (+8).
  • Formula: min(Entity_Weights + Tactic_Weights, 100) / 10.0.
  • Triage Tiers: CRITICAL (8.0–10.0), HIGH (6.0–7.9), MEDIUM, LOW.
