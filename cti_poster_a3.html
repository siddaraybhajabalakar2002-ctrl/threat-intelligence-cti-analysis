🚀 Steps Taken to Execute CTI Pipeline
1
Data Ingestion & Preprocessing: Gathered threat data from MISP feeds, CTI-HAL benchmark dataset, and security blogs; cleaned text with custom tokenizers.
2
Pipeline & Schema Architecture: Designed a modular decoupled pipeline separating entity extraction, tactic classification, and graph persistence.
3
IOC Extraction Engine: Implemented hybrid regex & spaCy NER to extract IPv4/IPv6, SHA256/MD5 hashes, domains, CVE numbers, and threat actor names.
4
MITRE ATT&CK TTP Mapping: Integrated a database of 100+ ATT&CK techniques; built semantic rule matching to classify attacker tactics & techniques.
5
Knowledge Graph & LLM Reasoning: Constructed NetworkX graph modeling threat entity relationships; integrated LLM interface for interactive threat Q&A.
6
REST API & Containerization: Built production Flask endpoints (/analyze, /knowledge_graph/query), containerized with Docker, and tested on real-world APT reports.
